② セキュリティ設計

外部とつながるのは ChatGPT API（OpenAI）だけ

接続先場所いつ・何のために
ChatGPT API（OpenAI）外部（唯一の接続先）質問に答えるとき（アプリ）／文書の索引づくりと検索（LightRAG）
LightRAG（文書検索）外部に出ない（いまはアプリと同じPC）文書を調べるとき（本番は IT 部門が用意するサーバの予定）
メールの中継サーバ管理者が指定（自社のサーバを想定）設定したときだけ（いまは未設定）
外部の部品・アクセス解析・自動更新なし使っていない（グラフの部品もアプリに同梱）

画面は外部のサイトから何も読み込みません（フォント・部品・アクセス解析なし）。
利用状況の送信や、自動更新の確認のような「裏の通信」もありません。

外部との通信は ChatGPT API（OpenAI）の1か所だけです。アプリは質問に答えるときに使い、文書検索の LightRAG も、文書の索引を作るときと検索するときに同じ API を使います。LightRAG 自体は、いまはアプリと同じPCで動いていて、文書の元のファイルは外部に出ません。本番では IT 部門が用意する LightRAG を使う予定で、そのときに使うAIは、その LightRAG の設定に従います（いまの設定は OpenAI）。メールは、管理者がメールの中継サーバを設定したときだけ使い、いまは設定していません。画面も外部のサイトから何も読み込まない作りで、グラフを描く部品もアプリに同梱しています。補足: ChatGPT API に送ったデータの扱い（学習に使われない等）は、API の契約と規約で確認した内容をここで添えてください。Webから情報を取ってくる「スクレイピング」の仕組みもありますが、いまは見本だけで、使っていません。
