質問と「道具の一覧」をAIに送る

アプリのコード（Python・説明用に短くしたもの）

# 道具の一覧（AIに見せるのは名前・説明・引数の形だけ）

tools = [{"type": "function", "function": {

"name": "run_sql_query",

"description": "読み取り専用のSELECT文を実行する",

"parameters": {"type": "object", "properties": {

"sql": {"type": "string"},

"purpose": {"type": "string"}},

"required": ["sql", "purpose"]}}}]

# 会話（最初は「決まりごと＋表の説明」と質問）

messages = [

{"role": "system", "content": 決まりごと + 表の説明},

{"role": "user", "content": "先月の不良件数は？"}]

resp = client.chat.completions.create(  # 外部へ送る

model=MODEL, messages=messages, tools=tools)

外部（ChatGPT API）に送るもの

  • 答え方の決まり（システムへの指示）
  • 表と列の説明（値の例・範囲、表ごとの見本3行まで）
  • 質問「先月の不良件数は？」
  • 道具の一覧（名前・説明・引数の形）

送らないもの

  • データベースのファイル・全件のデータ
  • 道具のプログラム・パスワード・APIキー
  • 利用者が対象から外した表の説明
  • 渡す道具は人によって変わる（管理者用の道具は一般の人に渡さない）
  • 実際の道具は40種類以上（SQL・グラフ・統計・Excel出力・文書検索 など）
ステップ1です。アプリは、質問と一緒に「道具の一覧」をAIに送ります。左のコードの tools が道具の一覧で、ここでは読み取り専用のSQLを実行する run_sql_query という道具を1つだけ書いています。AIに見えるのは、道具の名前と説明、それにどんな引数を受け取るか（sql と purpose）だけです。道具の中身のプログラムは見えません。messages は会話で、最初に「答え方の決まり」と「表と列の説明」、続けて利用者の質問を入れます。表と列の説明には、列の値の例や範囲、表ごとの見本が3行まで含まれます。最後の create で、これらをまとめて ChatGPT API に送ります。データベースのファイルや全件のデータは送りません。
