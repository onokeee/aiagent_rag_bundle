④ 使用技術

一般的な部品を、サーバ1台に組み合わせる

役割使っているもの
言語・サーバPython 3.13 ／ Flask ＋ waitress（32人分を同時に処理）
データベースSQLite（ファイル1つ「統合.db」。取り込み中でも読める方式）
AIChatGPT API（OpenAI。開発中は同じ作りのままローカルのAIに差し替え可）
AIと道具の連携ツール呼び出し（Tool Calling）：40種類以上の道具をAIが選び、アプリが実行
文書検索LightRAG（いまはアプリと同じPC。中で OpenAI の API を使う）
分析pandas・SciPy・statsmodels（集計・統計・予測）
出力Excel・Word・PowerPoint・グラフ（Plotly）
画面の部品HTML・CSS・JavaScript（外部からの読み込みなし）
使っている技術です。プログラムは Python で書いていて、画面とサーバは Flask と waitress という一般的な組み合わせです。データベースは SQLite で、ファイル1つにまとまっています。取り込みの最中でも利用者の検索が待たされない方式（WAL）にしています。AIは ChatGPT API（OpenAI）を使い、開発中は同じ作りのまま、このPCで動くAIに切り替えられます。AIとアプリの連携には「ツール呼び出し」という仕組みを使っています。次のページから、全体像とステップごとのコードを説明します。文書検索は LightRAG で、いまはアプリと同じPCで動き、索引づくりと検索に OpenAI の API を使っています（本番では IT 部門が用意する LightRAG を使う予定です）。分析は pandas などの定番の部品、出力は Excel・Word・PowerPoint に対応しています。画面は外部のサイトから部品を読み込まない作りです。
