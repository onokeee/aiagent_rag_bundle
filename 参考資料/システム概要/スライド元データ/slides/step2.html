外部（ChatGPT API）から返ってくる中身（例）

{"role": "assistant",

"content": null,  ← 文章は書かない

"tool_calls": [{

"id": "call_01",  ← 依頼の番号

"function": {

"name": "run_sql_query",  ← 使う道具

"arguments": {  ← 引数

"sql": "SELECT COUNT(*) AS 件数 FROM 品質__不良記録

WHERE strftime('%Y-%m', 発生日) = '2026-09'",

"purpose": "先月の不良件数を数える"}}}]}

  • AIは文章の代わりに「この道具を、この引数で」と依頼を返す
  • AIはデータベースに触れない。実行するかどうかはアプリが決める
  • 1回の返事に、依頼が複数入ることもある（順に実行する）
ステップ2です。AIからの返事には2種類あります。文章で答える場合と、道具を使ってほしいという「依頼」の場合です。右がその依頼の例です。content（文章）は空で、代わりに tool_calls に「run_sql_query という道具を、この引数で使ってほしい」と入っています。引数の sql には、AIが表の説明を見て書いたSQLが入っています。id は依頼の番号で、ステップ4で結果を返すときに「どの依頼への答えか」を示すのに使います。左のコードは、この返事を読む部分です。依頼があれば道具の名前と引数を取り出してステップ3へ進み、依頼が無ければ、それが最終回答なのでステップ5へ進みます。AIがデータベースに直接触れることはありません。依頼を実行するかどうかは、アプリが決めます。
