④ ツール呼び出し　まとめ

全体をつなげると、これだけのコード

# ステップ1: AIに渡す道具の一覧（名前・説明・引数の形）

tools = [{"type": "function", "function": {

"name": "run_sql_query",

"description": "読み取り専用のSELECT文を実行する",

"parameters": {"type": "object",

"properties": {"sql": {"type": "string"}}}}}]

messages = [{"role": "user", "content": "先月の不良件数は？"}]

for _ in range(10):  # 最大10往復

msg = client.chat.completions.create(  # ステップ2: 依頼か回答が返る

model=MODEL, messages=messages, tools=tools).choices[0].message

messages.append(msg)

if not msg.tool_calls:  # ステップ5: 依頼が無ければ最終回答

break

for call in msg.tool_calls:  # ステップ3・4: 実行して結果を返す

rows = run_select(json.loads(call.function.arguments)["sql"])

messages.append({"role": "tool", "tool_call_id": call.id,

"content": json.dumps(rows[:40])})  # 最大40行

1　道具の一覧を渡す

名前・説明・引数の形だけ。プログラムやデータそのものは渡さない

2　AIが「依頼」を返す

どの道具を、どの引数で使うか。AIが自分で実行することはない

3・4　アプリが実行して返す

渡した道具だけを実行（SQLは読むだけ）。返す結果は最大40行

5　依頼が無ければ終わり

その返事が最終回答。往復は最大10回

実際のアプリは、これに権限の確認・同じ依頼のくり返し防止・画面への逐次表示などを足したもの

ここまでのステップ1から5を、1つにつなげたコードです。Python で20行ほどの短い例ですが、仕組みはこれだけです。道具の一覧を渡し（ステップ1）、AIに聞くと依頼か回答が返り（ステップ2）、依頼ならアプリが実行して結果を返し（ステップ3・4）、依頼が無ければそれが最終回答です（ステップ5）。往復は最大10回、AIに返す結果は最大40行です。実際のアプリは、これに40種類以上の道具、利用者の権限の確認、同じ依頼のくり返しの差し戻し、エラーを分かる言葉に直す処理、画面への逐次表示などを足したものです。
