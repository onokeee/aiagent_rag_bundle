④ データの流れ

質問してから答えが出るまで

1　外部に出ない

利用者が日本語で質問する

2　外部に出ない

アプリが関係する表を選び、表の説明を添える

3　外部（ChatGPT API）

ChatGPT API が
使う道具と引数を決める
（ツール呼び出し）

4　外部に出ない＊

アプリが読むだけのSQL・文書検索を実行

5　外部へ送る

結果の一部をAIに返す（必要なら3〜5を繰り返す）

6　外部に出ない

回答・表・グラフを画面に少しずつ表示

AIは「どう調べるか」を考えるだけ。実際にデータを読むのは、外部に出ないアプリの中です。

＊文書検索のときは、LightRAG が検索の言葉を同じ ChatGPT API（OpenAI）に送ります

質問してから答えが出るまでの流れです。利用者が質問すると、アプリが関係しそうな表を選び、表と列の説明を添えて ChatGPT API に送ります。AIは「どの表を、どう集計するか」を決めて、前のページまでで説明したツール呼び出しの形でアプリに依頼を返します。実際にデータベースを読むのは、外部に出ないアプリの中で、読み取りだけのSQLを実行し、結果の一部をAIに返します。文書検索のときは、LightRAG が検索の言葉を同じ ChatGPT API に送って、関係する文書の抜粋を探します。足りなければこれを数回繰り返し、最後に回答・表・グラフを画面に少しずつ表示します。実行したSQLは回答に必ず残るので、何をどう数えたかを後から確かめられます。
