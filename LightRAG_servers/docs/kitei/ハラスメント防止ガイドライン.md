# ハラスメント防止ガイドライン

制定: 2020年6月1日　最終改正: 2026年4月1日
所管: 人事部 / ハラスメント相談窓口

## 1. 会社の方針

会社はいかなるハラスメントも許さない。
ハラスメントは、受けた人の尊厳を傷つけ、職場の力を失わせる。

## 2. ハラスメントの類型

### パワーハラスメント
職務上の地位や人間関係の優位性を背景に、業務の適正な範囲を超えて
精神的・身体的苦痛を与える行為。

**該当する例**
- 人格を否定する言動（「使えない」「辞めてしまえ」）
- 長時間の叱責、他の社員の前での見せしめ的な叱責
- 業務上明らかに不要なことや、遂行不可能なことの強制
- 仕事を与えない、隔離する

**該当しない例**
- 遅刻や規律違反に対する、必要な範囲での注意
- 業務上必要な指導や、達成可能な目標の設定

**「指導」と「パワハラ」の境目は、業務上の必要性と手段の相当性**である。
目的が正当でも、人格攻撃や過度な叱責は指導ではない。

### セクシュアルハラスメント
性的な言動により就業環境を害する行為。
本人が不快と感じるかどうかが基準であり、行為者の意図は関係しない。

### 妊娠・出産・育児休業等に関するハラスメント
制度の利用を妨げる言動、休業取得を理由とする不利益な取り扱い。

## 3. 相談窓口

| 窓口 | 連絡先 | 備考 |
|---|---|---|
| 社内相談窓口 | 人事部 ハラスメント相談担当 | 匿名可 |
| 外部相談窓口 | 契約先の相談ダイヤル | 社外の専門相談員 |

**相談したことを理由に不利益な取り扱いを受けることはない。**
相談内容の秘密は守られる。

## 4. 相談を受けたときの対応

1. 相談内容を記録する（本人の同意を得て）
2. 本人の意向を確認する（事実確認を望むか、聞いてほしいだけか）
3. **本人の同意なく、行為者へ連絡しない**
4. 事実確認は、相談者・行為者・第三者から公平に聴取する
5. 結果と対応を相談者へ説明する

## 5. 管理職の責任

管理職は、自らハラスメントを行わないことに加え、
**職場でハラスメントが起きていないか注意を払う義務**がある。
見て見ぬふりをした場合も責任を問われる。
