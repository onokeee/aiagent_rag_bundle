# 就業規則（抜粋）

制定: 2019年4月1日　最終改正: 2026年4月1日
所管: 人事部

## 第3章 勤務時間・休憩・休日

### 第15条（所定労働時間）
所定労働時間は1日**8時間**、1週40時間とする。休憩は12:00〜13:00の1時間。

| 勤務区分 | 始業 | 終業 |
|---|---|---|
| 日勤 | 08:00 | 16:45 |
| 夜勤 | 16:45 | 01:30 |

夜勤者には深夜割増（22:00〜05:00）を支給する。

### 第16条（休日）
土曜・日曜、国民の祝日、年末年始（12/29〜1/3）、夏季休暇3日とする。

### 第17条（時間外労働）
業務の都合により時間外労働を命ずることがある。
時間外労働は**事前申請**を原則とし、上長の承認を得ること。

**上限は月45時間・年360時間**とする。特別条項を適用する場合でも
月80時間・年720時間を超えてはならない。

月45時間を超えた社員には、人事部から本人と上長へ通知する。
**2か月連続で45時間を超えた場合は、産業医面談の対象**となる。

## 第4章 休暇

### 第22条（年次有給休暇）
入社6か月経過し、所定労働日の8割以上出勤した者に10日を付与する。
以後、勤続年数に応じて加算する（最大20日）。

| 勤続 | 付与日数 |
|---|---|
| 6か月 | 10日 |
| 1年6か月 | 11日 |
| 2年6か月 | 12日 |
| 3年6か月 | 14日 |
| 4年6か月 | 16日 |
| 5年6か月 | 18日 |
| 6年6か月以上 | 20日 |

**年5日は必ず取得させる**（法定義務）。取得日数が5日に満たない社員には、
人事部が時季を指定して取得させる。

### 第23条（特別休暇）
慶弔休暇、産前産後休暇、育児・介護休業（別途規程による）。

## 第5章 服務

### 第30条（遵守事項）
- 業務上知り得た秘密を漏らさないこと（退職後も同様）
- 会社の許可なく副業に従事しないこと
- 職場の秩序を乱す行為をしないこと

### 第31条（懲戒）
けん責・減給・出勤停止・諭旨退職・懲戒解雇の5種とする。
