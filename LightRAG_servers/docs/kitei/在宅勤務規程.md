# 在宅勤務規程

制定: 2022年4月1日　最終改正: 2026年4月1日
所管: 人事部

## 1. 対象者

在宅勤務を希望し、所属長が業務遂行に支障がないと認めた者。
ただし、**製造ラインに従事する者は対象外**とする（現場作業のため）。

## 2. 利用できる日数

| 区分 | 上限 |
|---|---|
| 通常 | **週2日まで** |
| 育児・介護の事情がある場合 | 週4日まで（別途申請） |
| 業務上必要と会社が認めた場合 | 制限なし |

## 3. 申請

前週の金曜日までに、所属長へ翌週の在宅予定を申請する。
急な在宅勤務は、始業1時間前までに連絡すれば認める。

## 4. 勤務時間

所定労働時間は出社時と同じ（8時間）。
**始業・終業時にチャットで所属長へ連絡**すること。

中抜けは認めるが、その時間は勤務時間に含めない。
中抜けが1時間を超える場合は、事前に所属長へ連絡する。

## 5. 環境と費用

| 項目 | 会社負担 | 自己負担 |
|---|---|---|
| 貸与PC・モニタ | ○ | |
| VPN・通信費 | 月2,000円を補助 | 超過分 |
| 電気代・光熱費 | 在宅勤務手当に含む | |
| 机・椅子 | | ○ |

**在宅勤務手当は月3,000円**（月8日以上在宅した月に支給）。

## 6. セキュリティ

情報セキュリティ規程に従う。特に次を守ること。

- 家族を含め、**他人が画面を見られる場所で作業しない**
- 公衆Wi-Fiでの業務は禁止（VPN必須）
- 紙の資料を自宅へ持ち帰らない

## 7. 在宅勤務中の事故

在宅勤務中の業務上の負傷は労災の対象になり得る。
私的行為中の負傷は対象外。判断が難しい場合は人事部へ相談すること。
