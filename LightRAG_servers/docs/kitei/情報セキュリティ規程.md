# 情報セキュリティ規程

制定: 2021年4月1日　最終改正: 2026年7月1日
所管: 情報システム部

## 1. 適用範囲

全社員および業務委託先。会社が貸与する機器・アカウント・データのすべて。

## 2. パスワード

| 項目 | 基準 |
|---|---|
| 最小文字数 | **12文字以上** |
| 文字種 | 英大文字・小文字・数字・記号のうち3種以上 |
| 有効期限 | **90日** |
| 再利用 | 過去5回分は使用不可 |
| 多要素認証 | 社外からのアクセスは**必須** |

**パスワードの共有は禁止**する。共有アカウントが必要な業務は、
情報システム部へ申請し、専用アカウントを発行する。

## 3. 貸与PCの取り扱い

- **持ち出しには事前申請が必要**（部長承認）
- 社外での作業は、のぞき見防止フィルタを使用すること
- 紛失・盗難時は、**発見後ただちに情報システム部へ連絡**（時間外は緊急連絡先へ）
- 個人所有PCでの業務は禁止（在宅勤務規程で認められた場合を除く）

## 4. 外部サービスの利用

会社の情報を外部のクラウドサービスへ保存する場合、**事前に許可が必要**。

| 分類 | 例 | 取り扱い |
|---|---|---|
| 許可済み | 社内指定のグループウェア・ファイル共有 | そのまま利用可 |
| 要申請 | 生成AI・オンラインストレージ・翻訳サービス | 情報システム部へ申請 |
| 禁止 | 個人アカウントのメール・SNSへの業務データ送信 | 一切不可 |

**顧客情報・図面・原価情報を、許可されていないサービスへ入力してはならない。**

## 5. メール

- 社外への添付ファイルはパスワード保護すること
- 宛先の誤りを防ぐため、送信前に宛先を音読して確認する
- 不審なメールの添付ファイル・リンクは開かず、情報システム部へ転送する

## 6. 退職・異動時

- アカウントは**退職日当日に停止**する
- 貸与機器は退職日までに返却する
- 業務データの持ち出しは一切禁止

## 7. 違反した場合

就業規則第31条の懲戒対象とする。故意の情報漏えいは懲戒解雇を含む。
