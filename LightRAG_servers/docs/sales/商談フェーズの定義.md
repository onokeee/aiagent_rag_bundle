# 商談フェーズの定義

所管: 営業企画部　最終改正: 2026年4月

## 1. なぜ定義を揃えるのか

担当者ごとに「見込みあり」の意味が違うと、予測が当たらない。
**フェーズは客観的な事実で判定する**（感触ではなく）。

## 2. フェーズ一覧

| フェーズ | 判定基準（すべて満たすこと） | 標準確度 |
|---|---|---|
| S1 リード | 名刺交換・問い合わせがあった | 10% |
| S2 ヒアリング | 課題と予算感を聞けた。担当者の名前が分かる | 20% |
| S3 提案 | 提案書を提出した | 40% |
| S4 見積 | 見積書を提出した。仕様が固まっている | 60% |
| S5 最終交渉 | 価格・納期の条件交渉に入った。決裁者が特定できている | 80% |
| S6 受注 | 注文書を受領した | 100% |
| 失注 | 他社決定・見送りが確定した | 0% |

**確度は担当者が勝手に上げ下げしない。** フェーズが上がれば確度も上がる。

## 3. よくある誤り

- **提案書を出す前に S3 にする。** 「出す予定」は S2 のまま。
- **決裁者が分からないのに S5 にする。** 誰が決めるか分からない案件は、
  条件交渉をしても最後にひっくり返る。
- **失注を放置する。** 負けた案件をフェーズのまま残すと、予測が水増しになる。
  **決まったら2週間以内に失注へ落とす。**

## 4. 受注予測

    受注予測額 = Σ（商談金額 × 確度）

月次の予測は S3 以上のみを対象とする。
S1・S2 は数が読めないため、予測には含めない（件数だけ見る）。

## 5. フェーズが2か月動かない商談

**停滞案件**として扱い、上長とのレビュー対象になる。
動かない理由は次のどれかであることが多い。

- 客先の予算が付いていない（時期を改めるべき）
- 決裁者に会えていない（担当者止まり）
- 競合が先行している（勝てる理由が無い）

**停滞したまま持ち続けるより、いったん失注に落として仕切り直すほうがよい。**
