# 提案書の型と勝ちパターン

所管: 営業企画部　最終改正: 2026年6月

## 1. 提案書の基本構成

提案書は次の順で書く。**この順番を変えないこと。**

1. **お客様の課題**（こちらの理解を示す）
2. **課題が解決されないとどうなるか**（放置のコスト）
3. **提案内容**（何をするか）
4. **なぜ自社なのか**（他社ではない理由）
5. **実績**（似た事例）
6. **価格と納期**
7. **進め方とスケジュール**

**価格を最初に出さない。** 価値を伝える前に価格を見せると、価格でしか比較されない。

## 2. 「お客様の課題」の書き方

ヒアリングで聞いた言葉を**そのまま使う**。
自社の言葉に翻訳すると、「分かってもらえていない」と感じさせる。

**悪い例**: 「生産性向上のご要望に対し」
**良い例**: 「『月末に組立が集中して残業が増える』という課題に対し」

## 3. 「なぜ自社なのか」の書き方

自社の強みを並べるのではなく、**その課題に対して**なぜ効くのかを書く。

| 強み | 効く場面 |
|---|---|
| 小ロット10個から対応 | 多品種・試作が多い客先 |
| 標準納期3週間 | 生産計画が直前に決まる客先 |
| 検査成績書を全ロット添付 | 保安部品・トレーサビリティが要る客先 |
| 設計者が同行できる | 仕様がまだ固まっていない案件 |

## 4. 実績の示し方

**同じ業界・同じ用途の事例**を1つ出す。数を並べても効かない。
守秘義務があるため、社名は「自動車部品メーカー様」等とし、
**課題・打ち手・結果**の3点で書く。

## 5. 勝ちパターン

過去の受注案件を分析すると、勝った案件には共通点がある。

1. **技術部門と早い段階で会えている**（仕様が固まる前）
2. **試作を受けている**（小ロット対応の強みが効く）
3. **課題を客先の言葉で説明できている**
4. 提案から見積まで**2週間以内**に進んでいる

逆に、購買部門だけと話し、仕様が固まった後に相見積で呼ばれた案件は、
**ほぼ価格勝負になり勝率が低い**（失注分析2026上期を参照）。

## 6. 提案後のフォロー

提案書を出したら、**3営業日以内に必ず連絡**する。
「ご不明点はありませんか」ではなく、
「◯◯の部分、社内でご検討いただけそうでしょうか」と具体的に聞く。
