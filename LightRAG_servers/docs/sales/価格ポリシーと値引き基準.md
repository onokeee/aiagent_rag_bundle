# 価格ポリシーと値引き基準

所管: 営業本部　最終改正: 2026年7月

## 1. 基本方針

値引きは**最後の手段**である。まず価値で勝負すること。
安さで取った案件は、次も安さでしか守れない。

## 2. 値引きの承認基準

| 値引率 | 承認者 | 備考 |
|---|---|---|
| 〜3% | 担当者判断 | 事後報告 |
| 〜7% | 課長 | 申請書に理由を記載 |
| 〜12% | 部長 | competitor情報の添付が必要 |
| 12%超 | 本部長 | 原則として認めない |

**値引きの理由に「競合が安いから」だけを書いてはならない。**
なぜその価格でも利益が出るのか、次につながるのかを書くこと。

## 3. 粗利の下限

| 製品区分 | 標準粗利率 | 下限 |
|---|---|---|
| 標準品（ブラケット類） | 28% | **20%** |
| 特注品（ハウジング類） | 35% | **25%** |
| 検査済アセンブリ | 30% | 22% |

**下限を下回る案件は、金額にかかわらず本部長承認**が必要。

## 4. 値引きの代わりに使える手

値引きを求められたとき、価格を下げる前に次を検討する。

- **数量のまとめ**: 年間契約にして単価を下げる（総額は増える）
- **納期の調整**: 繁忙期を外してもらう代わりに単価を維持
- **仕様の見直し**: 過剰な精度を落として原価を下げる
- **付帯サービス**: 検査成績書の付与、在庫の持ち合いなど

## 5. 見積の有効期限

見積書の有効期限は**発行から30日**とする。
材料費の変動が大きい時期は14日とすることがある（本部長判断）。

## 6. 値上げの申し入れ

原材料費が前年比10%以上上昇した場合、価格改定を申し入れる。
**改定は3か月前に予告する**こと。突然の通告は信頼を失う。
