# 主要顧客カルテ 東海自動車株式会社

更新: 2026年11月　担当: 営業1課

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| 取引開始 | 2018年 |
| 年間取引額 | 約1億2,000万円（自社売上の約18%） |
| 主要納入品 | ブラケットA（P-1001）・ブラケットB（P-1002） |
| 支払条件 | 月末締め翌月末払い |
| 与信枠 | 2,000万円 |

**自社にとって最大の顧客**であり、失うと事業への影響が大きい。

## 2. 組織と決裁

| 部署 | 担当 | 役割 |
|---|---|---|
| 購買部 | 課長 | 価格・納期の交渉窓口。**決裁は5,000万円まで** |
| 技術部 | 主任 | 仕様の決定。試作の可否を握る |
| 品質保証部 | 部長 | **不良発生時の窓口。ここの評価が取引継続を左右する** |

購買部だけを見ていると、技術部で仕様が決まった後に呼ばれることになる。
**技術部との関係作りが受注の鍵**である。

## 3. 現在の懸念（重要）

**2026年に品質クレームが2件発生している。**

| クレーム | 時期 | 内容 | 状況 |
|---|---|---|---|
| CL-001 | 7月 | ブラケットA 寸法不良 6個 | 対策済 |
| CL-002 | 8月 | ブラケットA 寸法不良 14個 | **対策中** |

**同じ品番で2件連続**しており、品質保証部の評価が下がっている。
11月の定例会で「次に出たら他社への切り替えを検討する」と言われている。

原因は製造部A装置のセンサー校正に関する問題で、社内では対策済み
（製造部の改善事例を参照）。**客先への説明資料を営業から提出する必要がある。**

## 4. 商談中の案件

新規ラインの立ち上げに伴い、2027年度から**年間4,000万円規模**の
引き合いが出ている。ただし品質問題が解決しない限り前に進まない。

## 5. 訪問時の注意

- 購買部への訪問だけで終わらせない。技術部・品質保証部にも顔を出す
- 品質の話題を避けない。**こちらから進捗を報告する**姿勢が信頼になる
- 価格の話は購買部としかしない（技術部にすると話がこじれる）
