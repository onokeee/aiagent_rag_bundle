# 競合A社対策メモ

所管: 営業企画部　更新: 2026年10月

## 1. A社の特徴

| 項目 | A社 | 自社 |
|---|---|---|
| 価格 | **安い**（自社比 −10〜15%） | 標準 |
| 納期 | 標準4週間 | **標準3週間** |
| 品質 | 寸法のばらつきが大きいとの評判 | 検査成績書を標準添付 |
| 小ロット対応 | 100個以上から | **10個から対応** |
| 技術対応 | 営業のみ。技術者の同行なし | **設計者が同行可能** |

## 2. 勝ち方

**価格で勝負しない。** A社より高いのは事実であり、そこを争えば必ず負ける。

### 勝てる場面
- **小ロット・多品種**: A社は100個未満を受けない
- **短納期**: 3週間対応は自社の強み
- **品質が効く用途**: 保安部品・外観部品では、ばらつきの少なさが効く
- **技術的な相談がある案件**: 設計変更を伴う案件は設計者同行で差が出る

### 負けやすい場面
- 単純形状・大ロット・長納期の案件（A社の土俵）
- 仕様が完全に決まっていて、購買部門だけで決まる案件

**負けやすい案件は、無理に追わず見極めることも大事**である。
勝てない案件に時間を使うと、勝てる案件を落とす。

## 3. よく聞かれる質問と答え方

**「A社はもっと安いですよ」**
→ 「はい、単価では負けています。ただ、御社の場合は小ロットでの
　　追加発注が多いので、**年間の総コストでは弊社が下回る**ことが多いです。
　　試算をお持ちしてもよろしいでしょうか」

**「品質は同じでしょう？」**
→ 「弊社は全ロットに検査成績書を付けています。
　　もし不良が出た場合、原因の切り分けにかかる時間が変わります」

## 4. 2026年上期の対戦成績

| | 件数 | 金額 |
|---|---|---|
| 勝ち | 14件 | 4,200万円 |
| 負け | 20件 | 7,605万円 |

負けた20件の内訳は、**価格で17件・納期で3件**。
価格で負けた17件は、いずれも「大ロット・長納期・単純形状」の案件であった。
自社の土俵ではない案件に時間を使いすぎている可能性がある。

（全社の失注は上期48件・1億6,200万円。そのうち価格理由が22件・8,600万円で、
A社に負けた17件はその内数。詳しくは「失注分析2026上期」を参照）
