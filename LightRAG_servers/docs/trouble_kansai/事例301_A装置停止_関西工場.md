# トラブル事例 No.301（関西工場）

**対象: 関西工場**（他拠点には適用しない）


| 項目 | 内容 |
|---|---|
| 発生日 | 2026年8月18日 |
| 設備 | A装置（関西工場） |
| 現象 | 検出センサー異常で停止 |
| 復旧時間 | 38分 |

## 原因

検出センサーの検出値ドリフト。関西工場のセンサーは本社より交換周期が短く、
周期管理が追いついていなかった。

## 処置

センサー交換と校正。関西工場の保全手順書に従い、締付トルクを守って実施した。

## 本社との違い

本社工場では同種の停止に47分かかった事例（事例152）があるが、
関西工場では38分で復旧している。設備の型式と部品の配置が違うため、
本社の復旧時間をそのまま目標にしてはならない。
