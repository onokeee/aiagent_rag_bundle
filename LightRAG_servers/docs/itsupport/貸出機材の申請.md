# 貸出機材の申請

所管: 情報システム部　更新: 2026年7月

## 1. 貸し出せるもの

| 機材 | 在庫 | 貸出期間の上限 |
|---|---|---|
| ノートPC（代替機） | 5台 | 2週間 |
| モバイルWi-Fi | 8台 | 1か月 |
| プロジェクタ | 3台 | 3日 |
| Webカメラ・マイク | 10台 | 1か月 |
| 大型モニタ | 4台 | 3か月 |
| タブレット（現場用） | 6台 | 1か月 |

## 2. 申請

**利用日の3営業日前まで**に申請してください。
繁忙期（4月・10月）は在庫が不足しやすいため、早めの申請を推奨します。

申請には次を記載します。
- 利用目的
- 利用期間（返却予定日）
- 持ち出し先（社外へ持ち出す場合）

## 3. 社外への持ち出し

**社外へ持ち出す場合は所属長の承認が必要**です（情報セキュリティ規程）。
海外へ持ち出す場合は、輸出管理の確認が別途必要になります。

## 4. 返却

- 返却予定日までに情報システム部へ返却してください
- **データは返却前に本人が消去**してください
- 破損・紛失した場合は、ただちに連絡してください

**返却が遅れると、次に借りる人が使えません。**
延長したい場合は、期限前に連絡してください（無断延長は不可）。

## 5. 破損・紛失

| 状況 | 費用負担 |
|---|---|
| 通常使用での故障 | 会社負担 |
| 明らかな過失（落下・水濡れ） | 部署負担 |
| 紛失 | 部署負担＋セキュリティ対応 |

紛失時は情報漏えいの恐れがあるため、
**PC故障時の対応**と同じく、ただちに連絡してください。
