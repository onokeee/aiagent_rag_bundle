# VPN接続手順

所管: 情報システム部　更新: 2026年9月

## 1. VPNが必要な場面

- 在宅勤務中に社内システムへアクセスするとき
- 出張先から共有フォルダを開くとき
- **公衆Wi-Fiを使うとき（必須）**

社内ネットワークに直結しているPCでは不要です。

## 2. 接続手順

1. 貸与PCで VPN クライアントを起動する
2. サーバー名は `vpn.company.local` （変更不要）
3. 社員番号とパスワードを入力する
4. **多要素認証のコード**を入力する
5. 「接続済み」と表示されたら完了

## 3. つながらないときの切り分け

順番に確認してください。

| 症状 | 確認すること |
|---|---|
| インターネット自体が繋がらない | Wi-Fi・有線の接続。他のサイトが開くか |
| 認証で弾かれる | パスワードの期限切れ。アカウントロック |
| 認証コードが届かない | 認証アプリの時刻ずれ。機種変更後の移行漏れ |
| 接続はできるが共有フォルダが開かない | ドライブの割り当て。`Z:` の再接続 |
| 極端に遅い | 自宅回線の速度。VPN経由の動画視聴は避ける |

**「つながらない」だけで連絡されても調べられません。**
上の表のどこまで確認したかを添えて連絡してください。

## 4. 同時接続数の制限

ライセンス数の都合で、**同時接続は150まで**です。
上限に達すると新規接続ができません（月曜朝に発生しやすい）。

作業が終わったら**必ず切断**してください。つなぎっぱなしにしないこと。

## 5. やってはいけないこと

- 個人所有PCからのVPN接続（在宅勤務規程で認められた場合を除く）
- VPN接続中の大容量ダウンロード（業務外）
- 認証情報を他人に教えること
