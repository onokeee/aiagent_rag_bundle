# PC故障時の対応

所管: 情報システム部　更新: 2026年8月

## 1. まず確認すること

連絡の前に、次を確認してください。切り分けが進みます。

1. **電源は入るか**（ランプは点灯するか）
2. **画面は映るか**（真っ暗か、何か表示されるか）
3. **エラーメッセージ**（あればスマートフォンで撮影してください）
4. 直前に何をしたか（アップデート、ソフトのインストール、水こぼし等）

## 2. 連絡方法

| 緊急度 | 連絡先 | 目安 |
|---|---|---|
| 業務が完全に止まる | 情報システム部 内線（直接） | 当日対応 |
| 業務は続けられる | 社内ヘルプデスク（チャット） | 2営業日以内 |
| 時間外・休日 | 緊急連絡先（重大障害のみ） | — |

## 3. 貸出機（代替機）

修理に時間がかかる場合、**貸出機を用意**します。

- 在庫は常時5台程度。繁忙期は不足することがあります
- 貸出期間は**原則2週間**
- データは**共有フォルダから復元**します。ローカルのみに保存したデータは戻せません

**重要なデータはローカルに置かず、共有フォルダに保存してください。**
PCが壊れてから「デスクトップにしかない」と言われても復元できません。

## 4. 修理の流れ

    連絡 → 切り分け → （必要なら）貸出機の手配 → メーカー修理 → 返却

メーカー修理は**平均7〜10営業日**かかります。
保証期間内は無償、期間外は部署負担です（見積を提示します）。

## 5. 水濡れ・落下

**すぐに電源を切り、電源ケーブルを抜いてください。**
乾かそうとして電源を入れると、通電でショートして基板ごと壊れます。

水濡れは保証対象外です。修理費は5〜15万円程度かかります。

## 6. 紛失・盗難

**発見後ただちに**情報システム部へ連絡してください（時間外は緊急連絡先）。
遠隔でロック・データ消去を行います。
警察への届出も必要です（情報セキュリティ規程）。
