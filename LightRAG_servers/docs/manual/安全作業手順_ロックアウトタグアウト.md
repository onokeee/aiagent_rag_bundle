# 安全作業手順 ロックアウト・タグアウト

適用: 製造部 全設備
管轄: 安全衛生委員会

## 1. 目的

保全作業中に、他の人が設備を動かしてしまう事故を防ぐ。
**設備の中に手を入れる作業は、すべてこの手順の対象**である。

## 2. 手順

1. 設備を停止し、主電源を落とす
2. 元弁を閉じ、**残圧を抜く**（圧力計 0MPa を目視確認）
3. 主電源の遮断器に**南京錠をかける**（ロックアウト）
4. 作業者名・作業内容・開始時刻を書いた**タグを付ける**（タグアウト）
5. 実際に起動操作をして、動かないことを確認する
6. 作業を行う
7. 作業後、工具や部品を残していないか確認する
8. タグと錠を**作業者本人が**外す

## 3. やってはいけないこと

- **他人の錠やタグを外すこと。** どんな理由があっても外さない。
  外す必要があるときは、保全課長と本人へ連絡する。
- 錠をかけずに「短時間だから」と作業すること。
  センサー交換の20分間でも対象である。
- 残圧を抜かずにカバーを外すこと。
  A装置・D装置はエア駆動部があり、残圧で可動部が動く。

## 4. 複数人で作業するとき

作業者それぞれが自分の錠をかける（多重ロック）。
最後の1人が作業を終えるまで、設備は起動できない状態を保つ。

## 5. 記録

ロックアウトを行った作業は、作業記録の備考に「LOTO実施」と記入する。
