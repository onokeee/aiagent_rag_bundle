# C装置 保全手順書（第1版）

対象設備: C装置（サーボ駆動プレス / 製造ライン2）
管轄: 製造部 設備保全課

## 1. サーボアラーム（E-310）の対応

C装置の停止で最も多いのはサーボアラーム E-310 である。
件数はA装置・B装置より少ないが、**1件あたりの復旧時間が長い**。

1. 制御盤のリセットを**1回だけ**行う。復帰すれば運転を再開する。
2. 再発した場合、リセットを繰り返してはならない。保全課へ連絡する。
3. 保全担当はサーボアンプのゲイン設定を標準値と照合する。
4. 設定が標準値と違っていれば戻す。合っていればメーカーへ連絡する。

**標準作業時間: 30分**（メーカー連絡が必要な場合を除く）

## 2. サーボアンプの標準設定値

| 項目 | 標準値 | 備考 |
|---|---|---|
| 位置ループゲイン | 45 | メンテナンス時に触ることがある |
| 速度ループゲイン | 120 | |
| トルク制限 | 85% | 型替え時も変更しない |

**メンテナンスで設定を変えたら、必ず元に戻すこと。**
戻し忘れると、後日まったく別の現象として現れ、原因の特定に時間がかかる。
過去に、戻し忘れたゲイン設定が63分の停止を招いた事例がある。

## 3. 交換周期

| 部品 | 型式 | 交換周期 |
|---|---|---|
| サーボモータ用エンコーダ | EN-52 | 36か月 |
| 電池（アブソリュートエンコーダ用） | BT-07 | 24か月 |

電池切れは原点位置の消失につながり、復旧に原点出しの作業が加わるため、
**周期前の交換を強く推奨する**。

## 4. 注意事項

C装置にはA装置のような検出センサーの校正作業は無い。
また、B装置のようなコンベア清掃も不要である。
C装置で確認すべきは、**設定値が標準どおりか**という一点である。
