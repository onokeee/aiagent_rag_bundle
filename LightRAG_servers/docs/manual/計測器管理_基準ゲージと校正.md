# 計測器管理 基準ゲージと校正

適用: 製造部 全ライン
管轄: 品質保証課（保全課が日常管理）

## 1. 基準ゲージ GA-14

A装置・D装置の検出センサー校正に使う基準ゲージ。
**保全課の工具棚B**に常備している。

| 項目 | 内容 |
|---|---|
| 型式 | GA-14 |
| 基準寸法 | 10.000mm |
| 許容差 | ±0.002mm |
| 校正周期 | **12か月**（外部校正機関） |
| 保管 | 専用ケース・防錆紙とともに工具棚B |

## 2. 校正期限を過ぎたゲージを使うとどうなるか

基準ゲージ自体がずれていると、**それに合わせたセンサーもずれる**。
装置は正常に見えるまま、寸法不良を作り続ける。
2026年8月に発生した寸法不良の増加（クレームNo.CL-002）は、
センサーの校正漏れが原因であったが、
「校正に使うゲージ自体が正しいか」も同時に確認すべき事項である。

**校正期限を過ぎたゲージは、赤いタグを付けて使用不可の棚へ移すこと。**

## 3. 日常の取り扱い

- 落下させたゲージは、期限内でも使用を止めて校正に出す
- 素手で長時間持たない（体温で膨張する）
- 使用前に汚れを拭き取る。研磨剤は使わない

## 4. その他の計測器

| 計測器 | 用途 | 校正周期 |
|---|---|---|
| 基準ゲージ GA-14 | センサー校正 | 12か月 |
| トルクレンチ | 締結 | 12か月 |
| ノギス（現場常備） | 寸法の抜き取り確認 | 12か月 |
| 圧力計（A装置・D装置） | 残圧確認 | 24か月 |

校正の記録は品質保証課が保管する。現場では**シールの期限だけ**を見ればよい。
