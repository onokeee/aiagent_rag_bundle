# A装置 保全手順書（第4版）

対象設備: A装置（型式 KМ-220 / 製造ライン1・ライン2）
管轄: 製造部 設備保全課

## 1. 検出センサーの交換手順

検出センサー（型式 SN-14）はA装置の消耗品であり、定期交換の対象である。

1. 主電源を落とし、元弁を閉じて残圧を抜く。圧力計が 0MPa を示すことを目視で確認する。
2. 安全カバーを外す。カバー固定ボルトは M6 が4本。
3. センサーのコネクタを抜いてから、センサー本体を引き抜く。
   コネクタを挿したまま引くと配線を断線させるため、順序を守ること。
4. 新品のセンサーを取り付ける。**締付トルクは 4.5N・m**。
   規定トルクを超えるとセンサー筐体が変形し、検出値が不安定になる。
5. 安全カバーを戻し、主電源を投入する。
6. 原点復帰を実行する。
7. **校正を行う**（第2章）。校正は省略してはならない。
8. テスト運転を3サイクル行い、検出値が規定範囲（±0.05mm）に入ることを確認する。

**標準作業時間: 25分**（校正・テスト運転を含む）

## 2. 校正手順

センサー交換後は必ず校正を行う。校正を省くと検出値が基準からずれたまま運転され、
数時間後に検出エラーで再停止する。これはA装置で最も多い再停止の原因である。

1. 操作パネルの「保守」→「センサー校正」を選ぶ。
2. 基準ゲージ（GA-14、保全課工具棚Bに常備）をセットする。
3. 「校正開始」を押し、完了表示が出るまで待つ（約90秒）。
4. 校正値をチェックシートに記録する。

校正に要する時間は約5分であり、上記の標準作業時間25分に含まれる。

## 3. 交換周期

| 部品 | 型式 | 交換周期 |
|---|---|---|
| 検出センサー | SN-14 | 6か月 または 稼働4000時間のいずれか早い方 |
| 安全カバーパッキン | PK-03 | 12か月 |
| 駆動ベルト | BL-88 | 24か月 |

周期を超えて使用した場合、検出値のドリフトが大きくなり、突発停止の頻度が上がる。

## 4. 部品の保管場所

検出センサー SN-14 は、保全課の部品棚 C-3 に常時2本を在庫している。
在庫が1本を切った時点で発注すること（納期は約2週間）。
