# 共通手順 締結とトルク管理

適用: 製造部 全設備
管轄: 設備保全課

## 1. なぜトルクを管理するのか

締めすぎは部品を壊し、緩すぎは運転中に外れる。どちらも突発停止につながる。
特に検出センサーは、規定トルクを超えると**筐体が変形して検出値が不安定になる**。
見た目では分からず、数時間後に検出エラーとして現れるため原因の特定が難しい。

## 2. 部品別の規定トルク

| 部品 | 型式 | 規定トルク | 備考 |
|---|---|---|---|
| 検出センサー | SN-14 | 4.5N・m | 超えると保証対象外 |
| 安全カバー固定ボルト | M6 | 8.0N・m | 4本を対角の順に締める |
| ガイドローラ固定 | GR-12 | 12.0N・m | 緩みやすいので毎月の点検対象 |
| エンコーダ取付 | EN-52 | 3.0N・m | 低めなので締めすぎに注意 |
| 搬送ベルトテンショナ | CB-40 | 15.0N・m | テンション調整後に本締め |

## 3. トルクレンチの管理

- トルクレンチは保全課の工具棚Aに常備。**年1回の校正**を受ける。
- 校正期限は本体のシールに記載。期限切れの工具は使用しないこと。
- 使用後は最小目盛りに戻して保管する（ばねのへたりを防ぐため）。

## 4. 締結の順序

複数のボルトを締めるときは、**対角の順に2回に分けて**締める。
1周目は規定トルクの60%、2周目で規定トルクに合わせる。
片側から順に締めると、部品が傾いて片当たりを起こす。

## 5. 記録

規定トルクを持つ部品を交換したときは、使用したトルクレンチの管理番号を
作業記録に残すこと（作業標準 STD-103）。
