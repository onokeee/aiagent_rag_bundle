# A装置 取扱説明書（抜粋）

型式 KМ-220 / メーカー: 光洋機械工業

## 検出センサー SN-14 の仕様

| 項目 | 仕様 |
|---|---|
| 検出方式 | レーザー変位 |
| 検出範囲 | 0〜30mm |
| 分解能 | 0.01mm |
| 許容誤差 | ±0.05mm |
| 電源 | DC24V |
| 締付トルク | 4.5N・m |
| 推奨交換周期 | 6か月 または 稼働4000時間 |

センサーは消耗品である。使用時間の経過とともに検出値がドリフトするため、
周期内であっても検出エラーが増えた場合は交換を検討すること。

## アラームコード

| コード | 意味 | 一次対応 |
|---|---|---|
| E-101 | 検出センサー異常 | センサーの汚れを確認 → 校正 → 交換 |
| E-102 | 原点復帰失敗 | 可動部の干渉物を除去して再実行 |
| E-205 | 圧力低下 | 元弁の開度・エア源を確認 |
| E-310 | サーボアラーム | 制御盤のリセット後に再起動。頻発するならメーカー連絡 |

E-101 が出た場合、いきなりセンサーを交換せず、まず汚れの確認と校正を試すこと。
汚れによる誤検出は清掃だけで復旧することが多く、その場合の復旧時間は10分程度で済む。

## 校正について

センサーを交換したとき、および検出値が疑わしいときは校正を行う。
校正を行わずに運転した場合、検出値が基準からずれたまま流動し、
不良の流出および数時間後の再停止につながる。

## 保証

センサー単体の保証期間は納入後12か月。ただし規定トルクを超えて取り付けた場合、
および校正を実施せずに運転して破損した場合は保証対象外となる。
