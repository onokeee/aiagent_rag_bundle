# D装置 保全手順書（第1版）

対象設備: D装置（型式 KМ-220 / 製造ライン2）
管轄: 製造部 設備保全課
導入: 2024年3月

## 1. A装置と同型式であること

D装置は**A装置と同じ型式 KМ-220** である。したがって、
検出センサー SN-14 の交換手順・締付トルク・校正の要否は
「A装置 保全手順書」とまったく同じ内容が適用される。

**A装置で行った改善は、D装置にも展開すること。**
2026年8月時点では、一次対応カードの掲示とセンサーの定位置化（改善事例087）が
D装置には展開されておらず、同じ原因の停止が起きている（事例160）。

## 2. 検出センサーの交換

手順はA装置と同一。要点のみ再掲する。

1. 主電源を落とし、残圧を抜く（圧力計 0MPa を目視確認）
2. コネクタを抜いてからセンサーを引き抜く（順序厳守）
3. **締付トルク 4.5N・m**
4. 原点復帰 → **校正**（省略禁止）→ テスト運転3サイクル

**標準作業時間: 25分**（A装置と同じ）

## 3. D装置に固有の注意

- ライン2に設置されているため、停止するとC装置の後工程が待ちになる。
  停止が15分を超える見込みなら、C装置の運転計画をライン長へ連絡すること。
- 導入が2024年と新しく、駆動ベルト BL-88 は初回交換をまだ迎えていない。
- 検出センサー SN-14 の在庫はA装置と共用（部品棚 C-3）。
  A装置とD装置が同時に故障すると在庫が足りなくなる。
