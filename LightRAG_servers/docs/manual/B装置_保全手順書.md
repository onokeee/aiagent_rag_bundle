# B装置 保全手順書（第2版）

対象設備: B装置（搬送コンベア一体型 / 製造ライン1）
管轄: 製造部 設備保全課

## 1. コンベア詰まりの解除手順

B装置の停止で最も多いのはコンベアの詰まりである。

1. 非常停止を押す。搬送モータが完全に止まったことを確認する。
2. 上流の投入を止める（前工程へ連絡）。
3. 詰まったワークを取り除く。手を入れる前に必ず非常停止であることを再確認する。
4. ベルト上の異物・粉塵を清掃する。
5. 非常停止を解除し、手動送りで1サイクル動かして引っかかりが無いことを確認する。
6. 自動運転に戻す。

**標準作業時間: 15分**

## 2. 詰まりが起きやすい条件

- ベルト清掃周期を超えている（粉塵の堆積で摩擦が増える）
- ワークの反りが基準（0.8mm）を超えている
- ガイド幅の調整が前ロットのまま

清掃周期は当初「月1回」であったが、改善活動により見直されている
（改善事例を参照）。

## 3. 交換周期

| 部品 | 型式 | 交換周期 |
|---|---|---|
| 搬送ベルト | CB-40 | 18か月 |
| ガイドローラ | GR-12 | 12か月 |

## 4. 注意事項

B装置にはA装置のような検出センサーの校正作業は無い。
B装置の停止時間が長引く場合、原因はコンベア以外（モータ・制御盤）の可能性があるため、
保全課へ連絡すること。
