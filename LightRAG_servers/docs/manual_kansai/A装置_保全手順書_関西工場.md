# A装置 保全手順書（関西工場）

**対象: 関西工場**（他拠点には適用しない）


対象設備: A装置（型式 KМ-330／関西工場）

## 1. 検出センサーの交換

1. 主電源を落とし、残圧を抜く（圧力計 0MPa を目視確認）
2. 安全カバーを外し、コネクタを抜いてからセンサーを引き抜く
3. 新品を取り付ける。**締付トルクは 5.2N・m**
4. 原点復帰 → 校正 → テスト運転3サイクル

**標準作業時間: 32分**

※ 本社工場のA装置は型式が違い、締付トルクも標準作業時間も異なる。
   関西工場の設備には、この手順書の値を使うこと。

## 2. 交換周期

| 部品 | 交換周期 |
|---|---|
| 検出センサー | 4か月または稼働3000時間 |

## 3. 部品の保管場所

検出センサーは 部品棚 K-2 に常備している。
