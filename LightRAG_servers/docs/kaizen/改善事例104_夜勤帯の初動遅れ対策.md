# 改善事例 No.104

| 項目 | 内容 |
|---|---|
| 実施時期 | 2026年11月（試行中） |
| 対象 | 全ライン・夜勤帯（Bシフト） |
| 担当 | 製造部 / 設備保全課 |
| 分類 | MTTR短縮 |

## 背景

停止記録をシフト別に集計したところ、
**夜勤（Bシフト）の復旧時間が日勤（Aシフト）より長い**傾向が見えた。

原因を調べると、設備の問題ではなく**保全体制の違い**であった。

| 項目 | 日勤（A） | 夜勤（B） |
|---|---|---|
| 保全課の常駐 | 3名 | **1名** |
| 部品の払い出し | 資材課が対応 | **保全担当が自分で探す** |
| 判断に迷ったときの相談先 | 課長・先輩 | **不在** |

夜勤帯は保全担当が1名のため、
他ラインの対応中に停止が重なると待ち時間がそのまま伸びる。

## 実施内容（試行）

1. **夜勤帯の一次対応範囲を広げる**
   オペレータが行える範囲を「清掃・校正」に加えて
   「**センサーの交換**」まで広げる。ただし訓練を受けた者に限る。

2. **夜勤用の部品キットをライン脇に置く**
   夜勤帯に必要になりやすい部品（SN-14・BT-07）を、
   ライン脇の保全キャビネットに1セット常備する（改善事例087の拡大）。

3. **判断に迷ったときの連絡先を明示**
   夜勤帯は保全課長の携帯へ直接連絡してよいことを、一次対応カードに明記した。

## 期待効果

夜勤帯の復旧時間を、日勤帯と同水準まで縮める。

## 検証方法

停止記録の shift_code で日勤・夜勤を分けて、
月別の MTTR を比較する。3か月継続して差が縮まれば本格導入とする。

## 備考

**同じ設備・同じ故障でも、時間帯によって復旧時間は変わる。**
設備の問題として見ていると、この差は見つからない。
