# 改善事例 No.101

| 項目 | 内容 |
|---|---|
| 実施時期 | 2026年10月 |
| 対象 | ライン1（品番切替） |
| 担当 | 製造部 第1係 |
| 分類 | 稼働率の向上 |

## 背景

ライン1では品番 P-1001（ブラケットA）と P-1002（ブラケットB）を
日によって切り替えて生産している。この段取り替えに時間がかかり、
生産できる時間が削られていた。

段取り替えは**計画停止**であり、突発停止（stop_records）には入らない。
そのため MTTR を見ていても、この損失は見えない。

## 実施内容

1. **外段取り化**
   次の品番の治具・ガイドを、ライン停止前に準備しておく。
   従来は停止してから工具棚へ取りに行っていた。

2. **ガイド幅の目盛り化**
   ガイド幅の調整を、現物合わせから**目盛りの数値合わせ**に変えた。
   品番ごとの設定値を一覧にしてラインに掲示。

3. **清掃を段取りに組み込む**
   B装置のベルト清掃（改善事例092で週1回に変更）を、
   段取り替えの待ち時間に行うようにした。追加の停止時間が発生しない。

## 効果

| 指標 | 実施前 | 実施後 |
|---|---|---|
| 段取り替え時間 | 45分 | 22分 |
| 1日あたりの切替回数 | 平均1.2回 | 変わらず |
| 月間で取り戻した生産時間 | — | 約9時間 |

## 学び

停止には**突発停止と計画停止**があり、改善の打ち手はまったく違う。

- 突発停止 → 原因の除去・初動の短縮（改善事例087・092）
- 計画停止 → 段取りの外出し・標準化（本件）

**MTTRは突発停止の指標**であり、段取り替えの改善効果はそこには表れない。
稼働率で見る必要がある。
