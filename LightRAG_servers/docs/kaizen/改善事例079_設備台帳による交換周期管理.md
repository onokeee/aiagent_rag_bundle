# 改善事例 No.079

| 項目 | 内容 |
|---|---|
| 実施時期 | 2026年6月 |
| 対象 | 全ライン |
| 担当 | 製造部 設備保全課 |
| 分類 | 突発停止の削減 |

## 背景

消耗品の交換周期を紙の台帳で管理していたため、記入漏れや確認漏れが起きていた。
周期を超えて使用したセンサーがドリフトし、突発停止につながる事例が続いていた。

## 実施内容

設備台帳システムに交換周期を登録し、期限の2週間前に保全課へ通知が出るようにした。
対象は検出センサー SN-14、搬送ベルト CB-40、ガイドローラ GR-12 など。

## 効果

登録した部品については、周期超過が月平均3件から0件になった。

## 残課題

2026年8月時点で、A装置の検出センサーは**まだシステムへ登録されていなかった**。
このため事例152では7か月使用のセンサーが検知されず、突発停止に至っている。
未登録の部品を洗い出し、順次登録することが必要である。
