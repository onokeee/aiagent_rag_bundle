# 改善事例 No.088

| 項目 | 内容 |
|---|---|
| 実施時期 | 2026年9月 |
| 対象 | ライン1（A装置）・ライン2（D装置） |
| 担当 | 品質保証課 / 製造部 第2係 |
| 分類 | 不良の流出防止 |

## 背景

2026年8月、寸法不良（D01）が客先へ流出した（事例150・クレームCL-002・14個）。
原因はセンサー交換後にテスト運転を省略し、検出値が安定しないまま
生産に戻したことであった。

不良の発生を月別に見ると、**8月にD01（寸法不良）が突出**していた。
設備は止まっていないため、停止記録（MTTR）を見ていても気づけない。

## 実施内容

1. **校正日の抜き取り検査を増やす**
   センサー交換・校正を行った日は、通常の抜き取り数を2倍にする。
   検査記録（inspections）の judge が NG なら、その時点でラインを止める。

2. **交換後チェックリストにテスト運転を明記**
   改善事例087で作ったチェックリストに、
   「テスト運転3サイクル・検出値を記録（規定±0.05mm）」の欄を追加した。
   記録欄を空にしたまま生産に戻せないようにした。

3. **品質と保全の記録を突き合わせる会議を月次で開催**
   不良の発生日と、保全作業の実施日を並べて確認する。

## 効果

| 指標 | 実施前（8月） | 実施後（10月） |
|---|---|---|
| 寸法不良 D01 の件数 | 大幅増 | 平常水準へ |
| 客先クレーム | 1件（CL-002） | 0件 |

## 学び

**「設備が止まっていない＝正常」ではない。**
止まらずに不良を作り続けるほうが、損害は大きくなることがある。
MTTRや停止件数だけでなく、**不良率と保全作業の日付を重ねて見る**必要がある。
