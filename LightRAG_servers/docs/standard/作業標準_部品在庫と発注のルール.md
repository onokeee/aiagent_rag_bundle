# 作業標準 STD-106 部品在庫と発注のルール

制定: 2026年5月1日
適用: 製造部 設備保全課

## 1. 目的

保全部品の欠品によって、復旧できない事態を防ぐ。

## 2. 発注点

各部品には**発注点**を定めている。
**在庫が発注点を下回ったら、その時点で発注する**（下回ってから考えない）。

    要発注 = 現在庫 <= 発注点

発注点は次の考え方で決める。

    発注点 = その部品を共用する設備の台数 + リードタイム中の想定消費数

**共用する台数を数え忘れないこと。**
検出センサー SN-14 はA装置とD装置の2台で共用しており、
1台分の在庫では足りない（改善事例095）。

## 3. リードタイム

発注してから届くまでの日数。部品によって大きく違う。

| リードタイム | 扱い |
|---|---|
| 7日以内 | 通常運用 |
| 8〜14日 | 在庫を切らさないよう注意 |
| **15日以上** | **在庫ゼロは許容しない。計画的に持つ** |

リードタイムが21日の部品が在庫ゼロなら、
故障した瞬間に3週間の停止が確定する。

## 4. 在庫の確認

- 部品を使ったら、**その日のうちに**使用実績を記録する
- 月末に現物と記録を突き合わせる（棚卸）
- 発注点を下回っている部品は、月次で一覧にして共有する

## 5. 交換周期との関係

作業標準 STD-103（部品交換・設定変更の記録要領）で、
交換周期は設備台帳システムが管理している。

**「いつ交換するか」（STD-103）と「部品があるか」（本標準）は別の管理**である。
交換予定が分かっていても部品が無ければ交換できない。
交換期限の通知が来たら、**在庫も同時に確認**すること。
