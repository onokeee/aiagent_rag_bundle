# 作業標準 STD-105 品質記録と不良の分類

制定: 2026年4月1日（2026年9月改訂）
適用: 製造部 全ライン / 品質保証課

## 1. 不良の分類

不良は次の5区分で記録する。**迷ったら現象で選ぶ**（原因ではなく）。

| 区分 | 名称 | 分類 | 見分け方 |
|---|---|---|---|
| D01 | 寸法不良 | 加工 | 測って基準から外れているもの |
| D02 | キズ | 外観 | 表面の傷・打痕 |
| D03 | バリ | 外観 | 縁の残り・削り残し |
| D04 | 組付不良 | 組立 | 部品の付け忘れ・向き違い |
| D05 | 異物混入 | 外観 | 切粉・ゴミの付着 |

**D01（寸法不良）は設備の状態と直結する。**
検出センサーの校正ずれ、治具の緩み、工具の摩耗が主な原因であり、
D01が増えたときは設備側を疑うこと。

## 2. 検査記録

抜き取り検査の結果は、測定値と判定を記録する。

| 項目 | 内容 |
|---|---|
| 検査日 | |
| 品番 | |
| ロット番号 | |
| 測定値 | 実測値（mm、小数第3位まで） |
| 判定 | OK / NG |

**判定基準: 基準寸法 10.000mm に対して ±0.05mm。**
これを外れたら NG とし、その時点でラインを止めて設備を確認する。

### 校正を行った日は抜き取りを増やす

センサーの交換・校正を行った日は、**通常の2倍**を抜き取る（改善事例088）。
校正直後は検出値が安定しないことがあるためである。

## 3. 客先クレーム

客先から不良の連絡があったときは、クレームとして記録する。

| 状態 | 意味 |
|---|---|
| 受付 | 連絡を受けた直後。原因は未調査 |
| 対策中 | 原因を特定し、対策を実施している |
| 対策済 | 対策が完了し、効果を確認した |

**受付から3営業日以内に「対策中」へ進めること。**
同じ客先・同じ品番で2件続いた場合は、品質保証課長へ即日報告する。

## 4. 直行率

**直行率 = 良品数 ÷ 投入数**

手直しして良品になったものは、直行率では**不良として数える**。
手直しの工数が見えなくなるためである。

## 5. 不良率

**不良率 = 不良数 ÷ 生産実績数**

不良数は同じ日・同じ品番の不良を合計する。
複数の不良区分がある場合も合算する。
