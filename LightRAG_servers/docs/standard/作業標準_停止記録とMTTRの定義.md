# 作業標準 STD-102 停止記録とMTTRの定義

制定: 2026年4月1日
適用: 製造部 全ライン

## 1. 目的

停止記録の書き方を統一し、MTTRの数値が部署間・月次間で比較できるようにする。

## 2. MTTRの定義

**MTTR（平均復旧時間）= 停止時間の合計 ÷ 停止件数**

停止時間は次の範囲とする。

    停止時間 = 自動運転が止まった時刻 → 自動運転に復帰した時刻

### 含めるもの

- オペレータによる一次対応の時間
- 保全課の到着を待っている時間
- 原因の切り分けに要した時間
- 部品交換・調整・校正の時間
- 復帰後の動作確認（テスト運転）の時間

### 含めないもの

- 計画停止（段取り替え・定期保全・清掃）
- 前工程の停止に伴う待ち（自設備は正常なもの）
- 材料切れによる停止

**注意**: 保全の待ち時間を含めるか外すかで数値は大きく変わる。
本標準では**含める**と定めている。設備の性能だけでなく、
組織としての復旧の早さを見るための指標であるため。

過去に「交換作業の時間だけ」を記録していた期間があり、
2026年3月以前の数値と単純に比較してはならない。

## 3. 記録項目

停止記録には次を記入する。

| 項目 | 備考 |
|---|---|
| 設備名 | A装置・B装置・C装置 |
| 発生時刻 / 復帰時刻 | 分単位 |
| アラームコード | 無い場合は「なし」 |
| 現象 | 見たままを書く |
| 原因 | 不明な場合は「調査中」でよい。推測を書かない |
| 処置 | 交換した部品の型式を必ず書く |
| 設定変更の有無 | 変更した場合は変更前の値も書く（事例155の反省） |

## 4. 起票の期限

停止記録は**当直内**に起票する。翌日に回すと内訳の時間が曖昧になり、
MTTRの内訳分析ができなくなる。
