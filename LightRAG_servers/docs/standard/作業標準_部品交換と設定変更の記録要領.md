# 作業標準 STD-103 部品交換・設定変更の記録要領

制定: 2026年9月1日（改善事例079・事例155にもとづく）
適用: 製造部 設備保全課

## 1. 部品を交換したとき

1. 設備台帳システムに交換日を登録する。次回の交換期限が自動で計算される。
2. 交換した部品の型式・ロットを停止記録に書く。
3. 取り外した部品は1週間保管する（原因調査のため）。

**設備台帳システムへの登録を省略しないこと。**
登録していない部品は交換期限の通知が出ず、周期超過による突発停止につながる
（事例152では未登録のセンサーが7か月使用されていた）。

## 2. 設定値を変更したとき

1. **変更前の値を必ず記録する**。
2. 一時的な変更であれば、作業終了時に元に戻す。
3. 恒久的な変更であれば、変更理由とあわせて保全課長の承認を得る。

設定を戻し忘れると、後日まったく別の現象として現れ、原因の特定に時間がかかる
（事例155では、戻し忘れたサーボゲインが63分の停止を招いた）。
