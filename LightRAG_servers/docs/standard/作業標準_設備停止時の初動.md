# 作業標準 STD-101 設備停止時の初動

制定: 2026年9月1日（改善事例087にもとづき改訂）
適用: 製造部 全ライン

## 1. 目的

設備が停止したとき、オペレータが迷わず動けるようにし、復旧までの時間を短縮する。

## 2. 手順

1. **停止を確認したら、まずアラームコードを読む**（操作パネル上段に表示）。
2. アラームコードごとの一次対応を、ライン脇の**一次対応カード**に従って実施する。
3. **停止から5分で復帰しない場合は、原因が分からなくても保全課へ連絡する**。
   原因の切り分けを待ってから連絡してはならない。待ち時間がそのまま復旧時間になる。
4. 保全到着まで、可能な範囲で情報を集めておく（発生時刻・直前の作業・異音の有無）。
5. 復旧後、停止記録を起票する（作業標準 STD-102）。

## 3. 一次対応の例

| アラーム | 一次対応 | オペレータが行う範囲 |
|---|---|---|
| E-101 検出センサー異常 | 清掃 → 校正 | 交換は保全課が行う |
| E-102 原点復帰失敗 | 干渉物の除去 → 再実行 | ここまで |
| E-205 圧力低下 | 元弁の開度確認 | ここまで |
| E-310 サーボアラーム | 制御盤リセット1回のみ | 再発したら即連絡 |

## 4. やってはいけないこと

- リセットの繰り返し。2回以上のリセットで復帰しない場合は必ず連絡する。
- 保全へ連絡せずに部品を交換すること。
- 校正を省略して運転に戻すこと。検出値がずれたまま流動し、不良の流出につながる。
