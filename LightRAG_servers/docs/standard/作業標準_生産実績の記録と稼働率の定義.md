# 作業標準 STD-104 生産実績の記録と稼働率の定義

制定: 2026年4月1日
適用: 製造部 全ライン

## 1. 目的

生産実績の記録方法と、稼働率の計算を統一する。
部署や月によって計算が違うと、改善の効果が判定できない。

## 2. 記録するもの

生産実績はシフトごと・設備ごとに1行で記録する。

| 項目 | 内容 |
|---|---|
| 日付 | 生産日 |
| ライン / 設備 | どこで作ったか |
| 品番 | 何を作ったか |
| シフト | A（日勤）／B（夜勤） |
| 計画数 | そのシフトで作る予定だった数 |
| 実績数 | 実際に良品として作れた数 |
| 稼働時間 | 実際に運転していた分 |
| 停止時間 | 突発停止で止まっていた分 |

## 3. 稼働率の定義

**稼働率 = 稼働時間 ÷ 所定時間**

所定時間は1シフトあたり **480分**（8時間）とする。休憩は含めない。

    稼働率 = run_minutes ÷ 480

### 含めるもの・含めないもの

| 区分 | 稼働時間に | 停止時間に |
|---|---|---|
| 正常に運転していた時間 | 含める | — |
| 突発停止（設備故障） | 含めない | **含める** |
| 段取り替え（品番切替） | 含めない | 含めない（計画停止） |
| 定期点検 | 含めない | 含めない（計画停止） |
| 材料待ち・前工程の停止 | 含めない | 含めない |

**段取り替えと定期点検は「停止時間」に入れない。**
これらは計画されたものであり、突発停止と混ぜると
MTTRも稼働率も意味が変わってしまう。

## 4. 計画達成率

**計画達成率 = 実績数 ÷ 計画数**

計画数はそのシフトで作る予定だった数であり、
設備が止まっても計画数は変更しない（変更すると達成率が常に100%になる）。

## 5. よくある間違い

- **稼働率と計画達成率を混同する。**
  設備が動いていても、狙いのスピードが出ていなければ計画は未達になる。
  稼働率が高いのに達成率が低いときは、サイクルタイムを疑う。
- **段取り替えを停止時間に入れる。**
  入れると停止時間が実態より大きくなり、MTTRの分子も狂う。
- **不良品を実績数に含める。**
  実績数は**良品の数**である。

## 6. 記録の期限

生産実績はシフト終了時までに入力する。
停止があった場合は、停止記録（STD-102）もあわせて起票する。
