# 品質基準（関西工場）

**対象: 関西工場**（他拠点には適用しない）


## 検査基準

| 項目 | 基準 | 備考 |
|---|---|---|
| 寸法公差 | **±0.03mm** | 本社（±0.05mm）より厳しい |
| 外観 | 目視全数 | |
| 抜き取り率 | **5%** | 本社は2% |

関西工場は精密部品の比率が高いため、本社より厳しい基準を採用している。
**本社の基準（±0.05mm）を関西工場に適用してはならない。**

## 不良が出たときの止め方

基準外が1個でも出たら、その時点でラインを止める（本社と同じ）。
ただし関西工場では、**止めた時点で品質保証課長へ即時連絡**する
（本社は当直内の報告でよい）。
