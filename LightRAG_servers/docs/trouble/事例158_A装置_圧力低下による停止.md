# トラブル事例 No.158

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年11月11日 |
| 設備 | A装置（ライン1） |
| 現象 | アラーム E-205（圧力低下）で停止 |
| 復旧時間 | 28分 |
| 起票者 | 製造部 第2係 |

## 経過

- 10:20 A装置が E-205 で停止。
- 10:22 オペレータが一次対応カードに従い、元弁の開度とエア源を確認。元弁は全開。
- 10:26 5分で復帰しないため保全課へ連絡（作業標準 STD-101 のルール）。
- 10:33 保全担当が到着。配管の継手からエア漏れを確認。
- 10:48 継手を締め直して復帰。

## 原因

エア配管の継手の緩み。振動で徐々に緩み、供給圧が規定を下回った。
安全カバーパッキン PK-03 の交換作業（10月）の際に、
継手を一度外して戻していたが、締め付けが不十分であった。

## 復旧時間の内訳

| 内訳 | 時間 |
|---|---|
| オペレータの一次対応 | 6分 |
| 保全到着まで | 7分 |
| 原因の切り分け | 7分 |
| 継手の締め直し・確認 | 8分 |

**5分ルール（STD-101）が守られたため、保全連絡が早く、全体で28分に収まった。**
同じA装置の8月の事例152では連絡までに8分かかっており、この点が改善している。

## 再発防止

- 配管を外す作業のあとは、翌日に増し締めの確認を行う
- 締結を伴う作業は、使用トルクを作業記録に残す（共通手順「締結とトルク管理」）

## 備考

E-205 はこれまで記録の少ないアラームだったが、
一次対応カードに載っていたためオペレータが迷わず動けた。
