# トラブル事例 No.152

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年8月12日 |
| 設備 | A装置（ライン1） |
| 現象 | アラーム E-101（検出センサー異常）で停止 |
| 復旧時間 | 47分 |
| 起票者 | 製造部 第2係 |

## 経過

- 08:14 A装置が E-101 で停止。オペレータが操作パネルをリセットするも再発。
- 08:22 保全課へ連絡。
- 08:36 保全担当が到着。センサーの汚れを確認したが軽微であった。
- 08:41 センサー交換を決定。部品棚 C-3 から SN-14 を取り出す。
- 09:01 交換完了。
- 09:01 自動運転に復帰。

## 原因

直接の原因は検出センサー SN-14 の検出値ドリフトである。
当該センサーは前回交換から**7か月**が経過しており、推奨交換周期の6か月を超えていた。

さらに、この停止では**復旧時間の内訳に問題があった**。

| 内訳 | 時間 |
|---|---|
| 発生から保全連絡まで | 8分 |
| 保全到着まで | 14分 |
| 原因の切り分け（汚れか故障か） | 5分 |
| 交換作業 | 20分 |

交換作業そのものは標準作業時間（25分）の範囲内であり、
**遅れの主因は保全到着までの待ち時間と、一次対応の判断に迷った時間**であった。

## 処置

センサーを新品に交換し、校正を実施したうえで復帰させた。

## 再発防止

- 交換周期の管理を目視の台帳から設備台帳システムへ移行する
- オペレータが行う一次対応（清掃・校正）の手順をラインに掲示する
- 保全課の応援要請ルールを見直す

## 備考

同月内に同じ E-101 での停止が2件発生しており、いずれも交換周期超過であった。
7月の同種停止（事例139）は復旧32分であり、8月は明らかに悪化している。
