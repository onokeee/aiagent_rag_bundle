# トラブル事例 No.148

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年8月3日 |
| 設備 | B装置（ライン1） |
| 現象 | 搬送コンベアの詰まりによる停止 |
| 復旧時間 | 18分 |
| 起票者 | 製造部 第2係 |

## 経過

非常停止のうえ、詰まったワークを除去。ベルト上に粉塵の堆積が見られたため清掃を実施し、
手動送りで確認してから自動運転へ復帰した。

## 原因

ベルト清掃の周期超過による摩擦増加。あわせて、当該ロットのワークに
基準（0.8mm）を超える反りが見られた。

## 処置

清掃および異物除去。前工程へワークの反りについて連絡した。

## 備考

B装置の停止は、その大半がコンベア詰まりである。
復旧時間は平均18分前後で安定しており、A装置ほどのばらつきは無い。
