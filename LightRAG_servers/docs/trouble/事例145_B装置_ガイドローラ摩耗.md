# トラブル事例 No.145

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年6月26日 |
| 設備 | B装置（ライン1） |
| 現象 | 搬送中にワークが斜行し、E-201（搬送詰まり）で停止 |
| 復旧時間 | 35分 |
| 起票者 | 製造部 第1係 |

## 経過

- 13:40 E-201で停止。詰まったワークを除去して復帰させたが、10分後に再発。
- 13:55 保全課へ連絡。ベルトの走行を観察したところ、片側に寄っていた。
- 14:05 ガイドローラ GR-12 の摩耗を確認。交換を決定。
- 14:15 交換完了、走行を確認して復帰。

## 原因

ガイドローラ GR-12 の摩耗。前回交換から**13か月**が経過しており、
推奨交換周期の12か月を超えていた。

摩耗したローラはワークをまっすぐ送れず、斜行して詰まりを起こす。
**通常のコンベア詰まり（平均18分）より復旧が長引く**のは、
最初の詰まり除去では直らず、原因の切り分けに時間がかかるためである。

## 処置

ガイドローラ GR-12 を交換。締付トルクは 12.0N・m。

## 見分け方

同じ E-201 でも、次の違いがある。

| 現象 | 原因 | 復旧の目安 |
|---|---|---|
| 単発の詰まり・除去で復帰 | 粉塵堆積・ワークの反り | 15〜20分 |
| 除去しても再発・ワークが斜行 | **ガイドローラの摩耗** | 30〜40分 |

**除去して再発したら、詰まりの除去を繰り返さずガイドローラを疑うこと。**

## 再発防止

ガイドローラを設備台帳システムの交換周期管理に登録した（改善事例079の対象拡大）。
