# トラブル事例 No.162

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年11月19日 |
| 設備 | C装置（ライン2） |
| 現象 | 起動時に原点位置を喪失。E-102（原点復帰失敗）で停止 |
| 復旧時間 | 72分 |
| 起票者 | 製造部 第3係 |

## 経過

- 06:30 朝の立ち上げ時、C装置が原点位置を保持しておらず起動できず。
- 06:40 保全課へ連絡。
- 06:55 アブソリュートエンコーダ用電池 BT-07 の電圧低下を確認。
- 07:10 電池を交換（部品棚 E-1 に在庫あり）。
- 07:42 **原点出し作業**を実施して復帰。

## 原因

エンコーダ用電池 BT-07 の寿命。前回交換から**26か月**が経過しており、
推奨交換周期の24か月を超えていた。

## なぜ復旧が長いのか

電池交換そのものは15分だが、**原点位置が消えると原点出しが必要**になり、
これに30分以上かかる。C装置の保全手順書にも
「電池切れは原点位置の消失につながるため、周期前の交換を強く推奨する」と
明記されている。

| 内訳 | 時間 |
|---|---|
| 発生から保全連絡まで | 10分 |
| 原因の特定 | 15分 |
| 電池交換 | 15分 |
| **原点出し** | **32分** |

## 教訓

これは**予防できた停止**である。
交換周期を過ぎていることが分かっていれば、計画停止の中で15分で済んだ。
突発になったことで72分を失った。

改善事例079で設備台帳システムに登録した部品に BT-07 は含まれていたが、
**通知は保全課にのみ届き、計画停止の予定に組み込まれていなかった**。

## 再発防止

交換期限の通知を、保全課だけでなく**生産計画の担当者にも配信**し、
計画停止の枠に組み込む運用へ変更した。
