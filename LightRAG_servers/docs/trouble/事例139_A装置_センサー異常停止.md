# トラブル事例 No.139

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年7月9日 |
| 設備 | A装置（ライン1） |
| 現象 | アラーム E-101（検出センサー異常）で停止 |
| 復旧時間 | 32分 |
| 起票者 | 製造部 第1係 |

## 経過

- 14:02 A装置が E-101 で停止。
- 14:05 オペレータがセンサー周辺を清掃したが復帰せず、保全課へ連絡。
- 14:12 保全担当が到着し、センサー交換を決定。
- 14:34 交換・校正完了、自動運転に復帰。

## 原因

検出センサー SN-14 の検出値ドリフト。前回交換から6か月経過しており、
推奨交換周期のちょうど境界であった。

## 復旧時間の内訳

| 内訳 | 時間 |
|---|---|
| 発生から保全連絡まで | 3分 |
| 保全到着まで | 7分 |
| 交換作業（校正含む） | 22分 |

オペレータが自分で清掃を試したうえで早めに連絡したため、
8月の事例152（47分）と比べて15分短く済んでいる。

## 処置

センサー交換および校正を実施。

## 備考

7月のA装置のMTTRは32分であった。
