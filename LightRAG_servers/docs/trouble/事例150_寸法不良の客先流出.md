# トラブル事例 No.150（品質）

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年8月28日（客先からの連絡） |
| 対象 | 品番 P-1001 ブラケットA（ライン1・A装置） |
| 現象 | 寸法不良（D01）が客先で発見された |
| 流出数量 | 14個 |
| 客先 | 東海自動車（クレームNo. CL-002） |
| 起票者 | 品質保証課 |

## 経過

- 08/28 客先より「取付穴の位置が基準から外れている」と連絡。
- 08/29 該当ロットを特定。8月中旬にA装置で加工したものと判明。
- 08/30 社内の在庫を全数選別。追加で23個の不良を発見し、出荷を止めた。

## 原因

**A装置の検出センサー交換後、校正を行わなかったこと**。

8月12日のセンサー交換（事例152）の後、校正を実施した記録はあるが、
その後の抜き取り検査で寸法のばらつきが増えていた。
調査の結果、校正に使用した基準ゲージ GA-14 は期限内であったが、
**校正後のテスト運転が3サイクル行われておらず、検出値の安定を確認しないまま
生産に戻していた**ことが分かった。

保全手順書には「テスト運転を3サイクル行い、検出値が規定範囲（±0.05mm）に
入ることを確認する」と明記されている。

## 影響

| 項目 | 内容 |
|---|---|
| 客先クレーム | CL-002（東海自動車・14個） |
| 社内で選別・廃棄 | 23個 |
| 選別工数 | 6人時 |
| 対応状況 | 対策中 |

同じ客先・同じ品番で、7月にもクレーム CL-001（6個）が発生している。
2件連続であり、客先の信頼に影響している。

## 処置

- 該当ロットの全数選別と客先への報告
- A装置の再校正とテスト運転の実施

## 再発防止

- **交換後のチェックリストに「テスト運転3サイクル・検出値の記録」を追加**（改善事例087で
  作成したチェックリストに項目を追加）
- 校正を行った日は、その直後の検査を通常より多く抜き取る（改善事例088）

## 備考

設備の停止記録（stop_records）には、この事例は**入っていない**。
設備は動いていたためである。**動いていても不良を作っていた**という点で、
停止時間だけを見ていては気づけない類の問題である。
