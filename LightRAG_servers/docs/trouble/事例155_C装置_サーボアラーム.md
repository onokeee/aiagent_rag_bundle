# トラブル事例 No.155

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年8月20日 |
| 設備 | C装置（ライン2） |
| 現象 | アラーム E-310（サーボアラーム）で停止 |
| 復旧時間 | 63分 |
| 起票者 | 製造部 第3係 |

## 経過

制御盤のリセットで一度は復帰したが、10分後に再発。
メーカーへ電話で問い合わせ、指示に従いサーボアンプの設定値を確認した。

## 原因

サーボアンプのゲイン設定が、前回のメンテナンス時から変更されたまま戻されていなかった。

## 処置

設定値を標準値に戻し、動作確認のうえ復帰。

## 再発防止

メンテナンス時に変更した設定は、作業記録に残して元に戻すことを徹底する
（作業標準の「部品交換・設定変更の記録要領」に追記済み）。

## 備考

C装置の停止は件数こそ少ないが、1件あたりの復旧時間が長く、
MTTRを押し上げる要因になりやすい。
