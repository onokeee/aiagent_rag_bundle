# トラブル事例 No.160

| 項目 | 内容 |
|---|---|
| 発生日 | 2026年8月28日 |
| 設備 | D装置（ライン2） |
| 現象 | アラーム E-101（検出センサー異常）で停止 |
| 復旧時間 | 55分 |
| 起票者 | 製造部 第3係 |

## 経過

- 09:05 D装置が E-101 で停止。
- 09:12 オペレータがリセットを試みるが復帰せず。**ライン2には一次対応カードが無く**、
  清掃・校正を試すべきか判断できないまま保全課へ連絡。
- 09:31 保全担当が到着。センサーの汚れを確認したが軽微。交換を決定。
- 09:38 部品棚 C-3 までセンサーを取りに戻る（ライン2からは片道5分）。
- 10:00 交換・校正完了、復帰。

## 原因

検出センサー SN-14 の検出値ドリフト。前回交換から8か月が経過しており、
推奨交換周期の6か月を超えていた。

**A装置とまったく同じ原因**である（事例152）。
D装置はA装置と同型式 KМ-220 であり、同じセンサーを使う。

## なぜ55分もかかったのか

A装置では2026年9月に改善（改善事例087）を実施し、MTTRを47分→35分に短縮した。
しかし**その改善がD装置には展開されていなかった**。

| 改善項目 | A装置 | D装置（当時） |
|---|---|---|
| 一次対応カードの掲示 | あり | **なし** |
| 保全応援要請の5分ルール | あり | **なし** |
| 交換部品のライン脇配置 | あり | **なし**（片道5分の往復） |
| 設備台帳への交換周期登録 | 2026年9月に登録 | **未登録** |

改善は「A装置で成功した」で終わっており、同型式のD装置への水平展開が漏れていた。

## 処置

センサー交換と校正。あわせてD装置にも一次対応カードを掲示し、
設備台帳へ交換周期を登録した。

## 教訓

**同じ型式の設備は、改善もセットで展開する。**
改善事例079（設備台帳）の「未登録の部品を洗い出す」という残課題が、
D装置では放置されていた。
