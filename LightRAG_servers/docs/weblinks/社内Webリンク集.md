# 社内Webリンク集

社内から使う外部サービスと、業務でよく参照するサイトの一覧。
リンク先が変わったときは、この文書を更新して再投入する。

## 1. 検索・調べもの

日々の調べものに使う一般的な検索サイト。

- Google（検索） https://www.google.com/
  もっとも一般的な検索サイト。社内規程・手順書に載っていない一般知識を調べるときに使う。
- Yahoo! JAPAN（ポータル） https://www.yahoo.co.jp/
  ニュース・天気・路線情報などをまとめて見るときに使う。出張前の天候確認によく使われる。
- Bing（検索） https://www.bing.com/
  Google が使えないときの代替。

## 2. 交通・移動（出張手配）

出張の申請前に、経路と所要時間をここで確認してから旅費を見積もる。

- Yahoo!路線情報（乗換案内） https://transit.yahoo.co.jp/
  電車の乗換と運賃を調べる。旅費精算に載せる金額はここの表示に合わせる。
- Google マップ（地図・経路） https://www.google.com/maps
  訪問先までの徒歩経路や所要時間の確認に使う。
- JR東日本 https://www.jreast.co.jp/
  運行情報。遅延で到着が遅れるときは、ここの情報を上長へ連絡する。
- ANA（航空券） https://www.ana.co.jp/
  国内出張の航空券。予約は総務経由で行う。
- JAL（航空券） https://www.jal.co.jp/

## 3. 天気・防災

工場の操業判断や、屋外作業の可否を決めるときに見る。

- 気象庁 https://www.jma.go.jp/
  警報・注意報の一次情報。避難や操業停止の判断はここを基準にする。
- Yahoo!天気・災害 https://weather.yahoo.co.jp/weather/
  地域ごとの天気を素早く見るとき。

## 4. 官公庁・法令

規程の改訂や、届出の様式を確認するときに使う。

- e-Gov 法令検索 https://elaws.e-gov.go.jp/
  法令の条文を確認する。社内規程の根拠を確かめるときに使う。
- 厚生労働省 https://www.mhlw.go.jp/
  労働安全衛生・労務関係の通達。
- 経済産業省 https://www.meti.go.jp/
- 国税庁 https://www.nta.go.jp/
  源泉徴収や消費税の取り扱いを確認するとき。
- 特許情報プラットフォーム（J-PlatPat） https://www.j-platpat.inpit.go.jp/
  特許・実用新案の調査。

## 5. 規格・標準

図面や品質基準で参照する規格の確認先。

- 日本産業標準調査会（JIS検索） https://www.jisc.go.jp/
  JIS規格の番号と内容を確認する。
- ISO https://www.iso.org/
- IPA（情報処理推進機構） https://www.ipa.go.jp/
  情報セキュリティの指針。ITサポートの手順の根拠にしている。

## 6. 業務で使う外部サービス

日常業務で開くことが多いサービス。ログインは各自の社用アカウントで行う。

- Microsoft 365 https://www.office.com/
  メール・予定表・Teams・SharePoint の入口。
- Google Workspace https://workspace.google.com/
- Zoom https://zoom.us/
  社外との打ち合わせ。社内は Teams を使う。
- Slack https://slack.com/

## 7. 参考: この一覧の使い方

- リンクが切れていたら、総務課へ連絡すること。
- 社内システム（勤怠・経費精算・図面管理）のURLは、この一覧ではなく
  各システムの利用手引きに記載している。
- ここに載せてよいのは、社外に公開されているサイトのみ。
  認証情報を含むURLや、社内限定の管理画面は載せない。
